# Count

Calm, stage-by-stage early maths path for pre-readers (voice + visuals).

**Live:** https://formone98127.github.io/maths-sense-kids/

## Developmental path (13 stages)

| # | Stage | Strand |
|---|--------|--------|
| 1 | More | Magnitude / more–less |
| 2 | Size | Qualitative size compare |
| 3 | Sort | Attributes |
| 4 | Flash | Subitizing |
| 5 | Count | One-to-one + cardinality |
| 6 | Pattern | AB patterning |
| 7 | Shape | Visual geometry |
| 8 | Match | Numeral ↔ quantity |
| 9 | Order | Stable order |
| 10 | Find | Numeral recognition |
| 11 | Join | Part–whole / combine |
| 12 | Take | Separate / take-away |
| 13 | Same | Conservation of number |

One ▶ button. Sound on recommended.
