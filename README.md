# Count

Calm, stage-by-stage early maths path for pre-readers (voice + visuals).

**Live:** https://formone98127.github.io/maths-sense-kids/

## Developmental path

Ordered after early-math trajectories (perceptual → iconic → symbolic / CPA):

| # | Stage | Strand |
|---|--------|--------|
| 1 | More | Magnitude / more–less |
| 2 | Sort | Attributes |
| 3 | Flash | Subitizing |
| 4 | Pattern | AB patterning |
| 5 | Shape | Visual geometry |
| 6 | Match | Numeral ↔ quantity |
| 7 | Order | Stable order |
| 8 | Find | Numeral recognition |
| 9 | Join | Part–whole / early combine |

One ▶ button. No reading required (sound on recommended).
