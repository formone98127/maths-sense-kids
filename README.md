# Count

A calm, stage-by-stage path for early number sense (ages ~3–6).

One button. Four stages. No game picker.

## Play

**Live:** https://formone98127.github.io/maths-sense-kids/

## Path

| Stage | Focus |
|-------|--------|
| Match | Numeral ↔ quantity |
| Order | Sequence |
| Find | Recognition |
| Flash | Subitising / memory |
